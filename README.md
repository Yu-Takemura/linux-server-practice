# Learning Notes(Day1)

## Permission Management

- Files created with sudo owned by root
- Normal users cannot modify those files
- Ownership can be changed using chown

## Keyboard Configuraion

- Different keyboard layouts can cause input mismatch
- It is necessary to cconfigure the keyboard layout in Ubuntu

## Git/GitHub

- Git requires user name and email configuration
- GitHub uses Personal Access Token instead of password
- Paste operation in terminal is different from normal applications

## Troubleshooting

- It is important to read error messages carefully
- Problems should be solved step by identifying the cause
